# Semantic Links for Obsidian

A privacy-first Obsidian plugin that suggests meaningful internal links while you write, including links where the wording differs but the underlying meaning is related.

The repository is currently in the planning stage. No plugin code has been implemented yet.

## Product direction

- Context-aware suggestions from the current sentence and paragraph
- Hybrid title, alias, keyword, graph, and semantic matching
- Local embedding inference by default
- Suggestions only; links are never inserted without user confirmation
- Desktop-first MVP, with mobile support assessed after the local-model implementation is proven
